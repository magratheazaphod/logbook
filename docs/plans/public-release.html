Making Logbook installable and forkable

Plan · agreed 2026-09-17 · audience: Claude Code users on macOS

Linux works minus Cowork and launchd. Sync, multiple users and hosting are explicitly out of scope. The architecture does not need to change; the remaining work is de-personalizing, packaging, trust signals and docs.

Already in place

  • Repo is public, with runtime data (board, handoffs, caches, backups) gitignored
  • README screenshots use synthetic data
  • Zero dependencies; app icon generated from source

What blocks a stranger today

  • No LICENSE file, so nobody may legally use or fork it.
  • Hardcoded personal settings: issue-match repos (ISSUE_MATCH_OWNERS / ISSUE_MATCH_REPOS), a Cowork session skip-list, and the com.jesse.logbook launchd label.
  • .claude/skills/logbook/SKILL.md is personal context, not project docs.
  • The launchd plist lives only in ~/Library/LaunchAgents; its PATH must reach claude or summaries fail with "Not logged in".
  • Prerequisites undocumented as required vs optional: transcripts, claude CLI, gh, macOS paths.
  • No tests or CI around a parser that depends on an undocumented format.
  • No tags, changelog, or stated board.json compatibility.

Plan - one PR per step

1

License and scope

MIT LICENSE. README gains "Who this is for" and "Not goals".

2

Config instead of hardcoding

Gitignored config.json plus committed config.example.json (or env vars) for issue-match repos, skip-list and launchd label. Issue match off by default. Startup banner lists active optional features.

3

Installer

./install.sh renders a committed plist template with the shell's PATH, loads it and health-checks localhost:8787; ./uninstall.sh reverses it.

4

Tests and CI

Stdlib unittest with synthetic transcripts (worktree, Cowork sidecar, malformed lines), the rev 409 guard, handoff path safety, backups. GitHub Actions on macOS and Linux. Pull ahead of 2-3 if feature work continues - it protects the live board too.

5

Split personal from project

Move the logbook skill to ~/.claude/skills; genericize CLAUDE.md, keeping the branch-and-PR rule.

6

README as a product page

Features, 2-minute install, configuration, privacy statement, upgrading. CHANGELOG.md, tag v1.0.0, GitHub description and topics.

7

Portfolio hook

Short case study on jesse-day.com linking the repo. No hosted demo - the app reads local transcripts, so a demo would be a facade; a GIF carries it better.

Before step 1

Scan the full commit history once for anything personal that predates the .gitignore - the repo has been public throughout. A quick grep found nothing.

Deferred, only on demand

pip or Homebrew packaging · a Linux systemd unit · Windows support
